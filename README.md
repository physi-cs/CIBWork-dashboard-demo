# CIBWork 运营看板原型

桌面优先的单页前端原型，使用本地 mock 数据，不连接业务后端。

## 启动

在项目目录依次运行 `npm install`、`npm run dev`。

## 页面与交互

- **用户流量**：会话数、DAU、Token 用量、耗时与异常率概览；Session、Trace、DAU 趋势和工具调用分布。
- **Token 用量**：总量、输入量、输出量趋势，以及模型维度用量分布；不展示缓存 Token。
- **性能耗时**：端到端与首 Token 的 P50/P90/P99 趋势；模型性能趋势支持调用耗时均值/P95/P99、首 Token P50/P90/P99、输出 TPS 切换，并可多选模型对比。悬浮显示当前值和调用样本数，点击时间点可下钻到对应 Trace。
- **质量状态**：对话异常趋势、模型/工具调用异常率趋势，以及模型和工具异常分布。
- 应用筛选仅提供“全部应用”和“QwenPaw”；任务场景筛选提供“全部场景”“对话服务”“自动化任务”。
- “会话追踪”保留在侧边栏作为暂未开放入口，本期不包含追踪列表和详情页。
- 页面使用白灰底色与 `#355eb8` 控件主色，指标卡和图表沿用原配色。
- 导出按钮会在浏览器中下载当前 mock 趋势为 Excel 可打开的 CSV 文件。

所有汇总与趋势数据位于 `src/mockData.js`。交互状态只保存在前端页面中。

## 离线预览包

仓库根目录的 [CIBWork-运营看板-离线预览.zip](./CIBWork-运营看板-离线预览.zip) 可转发给他人：解压后 Windows 双击 `start.bat`，macOS 双击 `start-mac.command`。macOS 需要 Python 3。预览服务只监听本机，不需要部署；启动窗口保持打开，按 Ctrl+C 停止。

## 项目结构

- `src/`：看板页面、样式和 mock 数据。
- `worker/`、`.openai/`、`scripts/`：Sites 静态应用托管配置。
- `tests/`：Sites worker 测试。
